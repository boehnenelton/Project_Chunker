Project Chunker snapshots project folders into BEJSON 104a snapshot databases (tracker, registry, snapshot, restore, scoop, zip intake, migrator; track/chunk/scoop/zip share one Chunk page; tracker details are edited for all versions of a project on the Projects page). This UI runs the same libraries as the CLI and menu, in-process, on this machine only.

Every state-changing request carries a per-process token; destructive operations need a matching preview and typed confirmations. Folders are chosen with the picker and confined to the configured roots.
