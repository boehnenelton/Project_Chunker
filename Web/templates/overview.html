How it works

  1. Plan — scan the project DB for zip archives and check each one is a complete, valid zip.
  2. Start — chunk and track every valid zip. Original zips are never touched in this phase.
  3. Verify — confirm each chunk against its zip, byte for byte, then delete, quarantine or keep the original.

Every run is a dry run until you switch it off in Configuration.
