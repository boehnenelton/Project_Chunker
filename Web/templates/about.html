Safety model

  • Dry run is the default; the first run only exports the config and a report.
  • A zip is chunked only if it passes a full CRC test, has no unsafe paths, symlinks or encryption, and extracts completely into a staging folder.
  • Start never changes a zip. Verify re-hashes the zip, checks the registry and snapshot, and (Deep verify) compares every file byte for byte.
  • A zip is deleted or quarantined only after it verifies and only on a live run. Partly captured zips are never removed.
  • Everything is recorded in the ledger; reports are written under migration/reports.
